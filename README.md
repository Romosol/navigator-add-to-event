# Navigator - add to event/Навигатор - создать заявку на новое мероприятие
**Скрипт, который добавляет детей на мероприятие в Навигаторе дополнительного образования**

## Установка

Для работы понадобится Python последней версии, библиотека Pandas и openpyxl для работы с таблицами .xclx и Selenium для управления браузером

Не забудьте выбрать при установке Pythin - Add python.exe to PATH

В командной строке введите:

```
pip install selenium pandas openpyxl
```

Для запуска введите:

```
python NavAddToEvent.py
```

При первом запуске вас попросят ввести логин, пароль, название мероприятия, дату и время

Введённые данные будут храниться в config.json

Программа автоматически открывает окно браузера, авторизируется на сайте и ждёт подтверждения для начала работы.

Шаги работы программы:
1. Открывает окно браузера
2. Авторизуется и ждёт команды на продолжение
3. Нажимает кнопку создать
4. Вводит название мероприятия, дату, время
5. Вводит ФИО ребёнка, выбирает из выпадающего списка ребёнка с подходящими ФИО и датой рождения
6. Проверяет подтверждён ли аккаунт ребёнка
7. Нажимает кнопку сохранить
8. Начинает заново с 3 шага

Если значение даты рождения пустое, то бот предложит выбрать ребёнка вручную
Если значение ФИО пустое, то ребёнок пропускается
Если аккаунт ребёнка не подтверждён, то предлагает выбрать ребёнка вручную
В файл list.xlsx введите список детей и даты рождения, начиная со второй строки
Также можно добавить в третий столбец муниципалитет ребёнка, который выводится в консоль
Программа записывает в 4 и 5 столбец обработан ли ребёнок и статус обработки

Дату в list.xlsx вводится в формате дд.мм.гггг
В ФИО не должно быть лишних или отсутствующих пробелов, спецсимволов
В результате работы программа создаёт 2 лог файла и конфиг

В конце работы программа и окно браузера закрываются
